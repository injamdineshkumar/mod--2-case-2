# Fuzzy Logic Medical Diagnosis System

A fuzzy logic-based system for medical diagnosis that handles imprecise and overlapping symptoms to provide accurate disease predictions.

## Overview

This system implements a fuzzy inference system that accepts symptoms with varying intensities and outputs possible diagnosis levels. It uses fuzzy logic to handle the uncertainty and imprecision inherent in medical diagnosis.

## Features

- **Fuzzy Inference System**: Uses triangular membership functions for symptom fuzzification
- **Multiple Disease Diagnosis**: Diagnoses Influenza, Common Cold, Pneumonia, and Chronic Fatigue
- **Rule-Based Reasoning**: Uses predefined fuzzy rules for disease inference
- **Batch Processing**: Can process multiple patients from CSV files
- **Interactive Mode**: Allows manual symptom input for diagnosis
- **Confidence Scoring**: Provides confidence levels for each diagnosis
- **Treatment Recommendations**: Suggests treatments based on diagnosis
